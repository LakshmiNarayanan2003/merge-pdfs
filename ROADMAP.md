# Roadmap

Future items are exploring/planned, not current features or delivery promises.

## v0.1.0 — Current core

- Merge, document/page reorder, rotate/remove/restore, selection edits, ranges and local validated downloads.
- Bounded previews, cancellable merge worker, samples and automated checks.

## v0.2.0 — Planned advanced editing

Explore duplicate pages, crop, blank-page insertion, page numbering and richer multi-step undo. Preserve deterministic page identity and resource limits.

## v0.3.0 — Exploring preservation

Investigate bookmarks/outlines and destination remapping, safe form flattening, annotation behavior and a broader complex-font/accessibility-tag corpus. Encrypted merge only if a secure local content-preserving solution is verified.

## v0.4.0 — Exploring additional tools

Split/extract pages, PDF metadata editing and carefully labeled compression. No server fallback, paid quotas or tracking. Additional tools must retain the same local privacy boundary.
